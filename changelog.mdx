<Update label="June 4, 2026" description="Initial public release">

The Poultry Farm Analytics API is now available. This first release covers the full v1 surface plus the new unified v2 analytics service.

## New features

- **Analytics V2** — Unified analytics service with daily metrics, cycle analysis, breed comparison, predictions, anomaly detection, root cause analysis, batch tracking, and financials. See [Analytics V2](/api-reference/overview).
- **Authentication and roles** — JWT-based signup, login, verification, and role management. See [Authentication](/api-reference/overview).
- **Dashboards** — Role-specific summaries for flock, supervisor, and admin views. See [Dashboard](/api-reference/overview).
- **Inventory** — Track movements for birds, feed, and eggs, including day locking, balances, and egg productivity. See [Inventory](/api-reference/overview).
- **Flocks and cycles** — Manage flocks, production cycles, and operational [Schedules](/api-reference/overview). See [Flocks](/api-reference/overview) and [Cycles](/api-reference/overview).
- **Rule engine** — Build, test, and alert on custom analytics rules with formula inputs and calculations. See [Rules](/api-reference/overview).
- **Anomaly detection** — List, create, and resolve detected anomalies across your operation. See [Anomalies](/api-reference/overview).
- **Predictive insights** — Failure forecasting, maintenance schedules, and flock health forecasts. See [Predictive](/api-reference/overview).
- **Compliance tracking** — Requirements, violations, and per-flock compliance status. See [Compliance](/api-reference/overview).
- **Business continuity** — Recovery plans and recovery time estimates per flock. See [Continuity](/api-reference/overview).
- **Optimization** — Efficiency opportunities and per-flock recommendations. See [Optimization](/api-reference/overview).
- **Resource sharing** — Share and transfer resources between flocks and farms. See [Sharing](/api-reference/overview).
- **IoT integration** — Register devices and ingest sensor data. See [IoT](/api-reference/overview).
- **Procurement, operations, and scale** — Endpoints for [Procurement](/api-reference/overview), [Operations](/api-reference/overview), and [Scale](/api-reference/overview) workflows.
- **Admin control plane** — Manage models, anomaly rules, users, audit logs, and system health. See [Admin](/api-reference/overview).

## Getting started

- Read the [API overview](/api-reference/overview) for base URL, authentication, and conventions.
- Follow the [Quickstart](/quickstart) to make your first authenticated request.
